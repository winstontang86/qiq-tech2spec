## 1. 总体覆盖率（**机械计数口径，分母可复算**）

> “一条 = 一个覆盖单元（coverage unit）”，按下表**机械规则**切分，避免主观颗粒度。任何人按同一规则复算，必须得到相同的分母 `N`。

### 1.1 覆盖单元计数规则

每满足以下一项计 **1** 个覆盖单元：

| 类别 | 计数规则（每 1 个计 1） |
|---|---|
| 编号小节 | 技术方案中每个**最小编号叶子小节**（有 `§x.y` / `§x.y.z` 且其下无更深编号小节者） |
| 数据表 | 每张表（`CREATE TABLE` 对应的一张业务表） |
| Redis key | 每一类 Redis key 模板 |
| 对外接口 | 每个对外接口方法（HTTP 每个 path+method / RPC 每个 method / MQ 每个 topic 的生产或消费契约） |
| 错误码 | 每个业务错误码 |
| mermaid 图 | 每张 mermaid 时序图 / 流程图 / 状态机 |
| 故障/异常路径 | 方案“故障与异常路径汇总”表的每一行 |
| SLO/容量 | 每个 SLO 指标 / 每个容量参数 |

> 去重规则：同一实体在“编号小节”与“数据表/接口/错误码”中重复出现时，**按最细粒度那一类计数**（表 / 接口 / 错误码 / 故障行 / SLO 优先于其所属编号小节），避免重复计入。计数时以本表列出的实际条目为准。
